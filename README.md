# 🏫 쉬는 시간 스마트 알람 & 타이머 (Smart Break Timer)

학교 및 교육 기관의 **스마트 칠판**, **대형 전자교탁 모니터**, **교실 TV(16:9 비율)**에 최적화된 웹 기반 **쉬는 시간 스마트 알람 & 타이머 앱**입니다.

별도의 설치나 서버 구동 없이, 교실 PC에서 **`index.html` 파일을 더블 클릭**하기만 하면 인터넷 연결 여부와 상관없이 즉시 완벽하게 작동합니다.

---

## 🌟 주요 기능 및 특징

### 1. 16:9 대형 디스플레이 완벽 대응
- **황금 분할 레이아웃**: 좌측(40%) 시간/타이머 영역 + 우측(60%) 교과 연계 미디어 및 준비물 정보 영역
- **고해상도 반응형**: FHD(1920×1080), 4K(3840×2160) 등 모든 16:9 스크린에 레터박스 없이 꽉 찬 화면 유지
- **원거리 가독성 특화**: 교실 맨 뒤 학생 책상에서도 선명하게 인지할 수 있는 초대형 폰트와 고대비 타이포그래피

### 2. 실시간 시계 & 원형 프로그레스 타이머
- **실시간 날짜/시계**: 연/월/일, 요일, 오전/오후 및 초 단위 펄스 시계
- **원형 게이지 카운트다운**: 부드러운 SVG 링 애니메이션과 함께 직관적인 잔여 시간 표시
- **원터치 시간 조절**: `[+1분]`, `[+5분]` 추가 버튼 및 `5분` / `10분` / `15분` / `20분` 원클릭 프리셋 칩

### 3. 3단계 시각 및 청각 알림 시스템
1. **평상시 (Normal)**: 차분한 네이비/민트 컬러로 편안한 휴식 분위기 조성
2. **1분 전 경고 (Warning)**:
   - 타이머 전체가 주황/앰버 색상으로 변하며 은은한 펄스 글로우 애니메이션 작동
   - 맑고 부드러운 사전 차임벨(솔-도) 1회 자동 울림
   - "⚠️ 1분 전! 다음 수업을 준비해 주세요" 알림
3. **종료 (Timeout, 00:00)**:
   - 네온 코랄/레드 점멸 효과 및 "🔔 수업이 시작되었습니다!" 텍스트 전환
   - **한국 학교 딩동댕동 4음 멜로디(미-도-레-솔)** 2회 연주 (Web Audio API 실시간 합성음)

### 4. 교과 연계 수업 준비 및 미디어 쇼케이스
- **9개 교과 프리셋**: 수학, 국어, 영어, 과학, 사회, 미술, 음악, 체육, 자율/창체
  - 각 과목 선택 시 시그니처 아이콘, 대표 컬러, 기본 준비물 체크리스트, 교실 공지, 감성 명언 자동 연동
- **멀티 미디어 탭**:
  - `📋 수업 준비물 & 공지`: 책상 위 준비물 체크리스트 및 선생님 칠판 당부 말씀
  - `🧘 쉬는 시간 스트레칭`: 눈 피로 해소, 척추 기지개, 목 회전 등 15초 주기 건강 가이드
  - `📺 영상 / 이미지`: 외부 유튜브 스트레칭 체조 영상 임베드 또는 학교 행사 포스터/시간표 이미지 띄우기

### 5. 다채로운 테마 및 사용자 맞춤 설정
- **3가지 시각 테마**:
  - `🌙 다크 모드`: 눈부심을 최소화한 편안한 다크 네이비 테마 (기본값)
  - `📗 초록 칠판 모드`: 학교 분필 칠판 감성의 아늑한 그린 테마
  - `☀️ 밝은 모드`: 화사하고 깔끔한 교실 분위기의 라이트 테마
- **환경 설정 모달 (⚙️)**:
  - 학급 명칭(예: 3학년 2반), 기본 쉬는 시간 분 단위 자유 설정
  - 준비물 및 공지사항 내용 자유 편집
  - 알림음 볼륨 조절, 사전 차임벨 On/Off, 종소리 미리듣기 지원
  - 모든 설정은 브라우저 `localStorage`에 자동 보관되어 컴퓨터를 껐다 켜도 그대로 유지

## ⌨️ 편리한 키보드 단축키

선생님께서 무선 프리젠터나 키보드로 교실 어디서든 손쉽게 조작할 수 있습니다.

| 단축키 | 기능 |
|:---:|:---|
| **Space** | 타이머 시작 / 일시정지 |
| **F** | 전체화면 모드 전환 / 해제 |
| **S** | 설정 모달 창 열기 |
| **R** | 타이머 초기화 (처음 설정 시간으로 리셋) |
| **+** 또는 **=** | 타이머 1분 즉시 추가 |
| **Esc** | 열려있는 설정 모달 닫기 |

## 🚀 실행 방법

1. 본 폴더에 있는 **`index.html`** 파일을 Chrome, Edge, Whale 등 모던 브라우저로 실행(더블 클릭)합니다.
2. 키보드의 **`F`** 키를 누르거나 상단 우측의 **`[⛶ 전체화면]`** 버튼을 클릭하여 스마트 칠판 전체화면으로 전환합니다.
3. 상단 우측의 **`[⚙️ 설정]`** 버튼을 눌러 학급명과 다음 수업 정보를 입력한 후 **`[▶ 시작하기]`**를 누르면 바로 쉬는 시간 안내가 시작됩니다.
